# Site Search

**Site Search Tracking** gives you insights into what your visitors are searching for on your website.

## How it works

Betterlytics integrates with the native WordPress search function (`is_search()`). When a visitor performs a search, the search query is captured and sent to your dashboard.

## Data Captured

*   **Event Name**: `search`
*   **Property**: `query` (The actual search terms used, e.g., "pricing", "contact")
